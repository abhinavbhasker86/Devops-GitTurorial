--Git Commit and Logs commands:
	git status -- this shows any chnages in direcory. Uncommited files will appear in red color. Post add, they will appear green.
	git diff  -- This command will show the changes made in already commited file and show the difference.
	git add . -- This command put all the changes into staging Area
	git commit -m "Commemnts" -- This will commit the file in git repository with comments
	git commt --if you just do this and press enter, it will open an editor to put comments. you can add multiline comments here.
	git log  -- This command will show last 10 commits (all authors) in Desc order. with info commit number, Author, Date and time, Commit Comment.
	git log --author="<<Author Name>> or <<Email Id>>" -- This command is used to identify commits done by specific Author.

-------------------------------------------Generic Commands-------------------------------------------
-- command to create a file direcly from bash
	touch <<filename>>
--use vi command to edit file using bash
	vi <<filename>>
	press "Esc" to come out of edit mode
	and use below commands to make chages:
	To Save (and Exit)

	Once you’re in command mode (after pressing Esc):

	Action	Command	Explanation
	Save file (without exiting)	":w"	--Writes (saves) your changes
	Save and exit	":wq"	--Writes changes and quits
	Save and exit (shortcut)	"ZZ" --(uppercase)	Same as :wq
	Exit without saving	":q!"	--Quits and discards changes
